# Viral to Value · Ping 체험하기

코드잇 데이터 분석 15기 7팀의 클릭형 UI/UX 프로토타입입니다.

- 눌러보기: 실제 화면의 버튼을 누르며 흐름을 체험합니다.
- 전체 화면: 198개 화면·상태를 찾아보고 해당 화면을 엽니다.
- Ice Bloom / Midnight Club / 두 모드 비교를 지원합니다.
- 휴대전화에서는 기본으로 Ice Bloom 한 화면을 보여줍니다.

`index.html` 하나에 화면과 기능이 모두 포함되어 있습니다. 다운로드하여 브라우저로 열거나 GitHub Pages에서 사용할 수 있습니다.

## 시연 안내

학교, 인물, 메시지, 수치, 결제 조건은 시연 예시입니다. 실제 회원가입, 문자, 메시지, 결제, 추천 모델과 연결되어 있지 않습니다. 개인정보는 입력하지 마세요. 입력 내용과 시연 상태는 서버로 전송하거나 저장하지 않으며 새로고침하면 초기화됩니다. 화면에 표시되는 `.example` 주소와 QR은 실제 서비스 링크가 아닙니다.

GitHub Pages 접속 시 호스팅 서비스의 일반적인 접속 처리는 별도로 이루어질 수 있습니다. 이 페이지 자체에는 분석 추적기나 외부 전송 기능이 없습니다.

내부 개선 설명, 반영표, 설계 기준, 기존 화면 재현 및 Figma 가져오기 자료는 배포 파일에 포함하지 않았습니다.
